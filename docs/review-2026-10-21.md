# Maintenance and source review — 21 October 2026

This follow-up checks execution, saved-result interpretation, source metadata, and Windows portability. It preserves the [20 October review](review-2026-10-20.md), raw public capture, synthetic inputs, and historical output directories.

## What changed

Generated JSON, Markdown, and SVG now use explicit UTF-8 with LF line endings. Previously, the Windows default encoding could produce an SVG containing invalid UTF-8 bytes despite successful numerical computation. A regression test now decodes the generated files and parses the SVG as XML.

The chart footer now takes its date window and capture date from the validated snapshot. It no longer stamps every future capture with the original October 20 date. A synthetic metadata fixture tests this behavior without pretending to be a second real CDC capture.

The test for rejecting a symbolic-link snapshot is separate from tests of exception categories. It runs when the platform permits creating a link and records a capability skip otherwise. The existing Linux CI job retains the link-rejection test; lack of Windows permission no longer hides the unrelated exception checks or fails the whole suite.

## Source and scientific interpretation

The [official CDC dataset metadata](https://data.cdc.gov/api/views/rgnm-fkqb.json) were accessible during this review. They describe voluntary aggregate NAAT reporting, variable participation, provisional and revisable data, and tests rather than unique patients. For national/regional rows, `tests` and `detections` are current-week counts. The live definition identifies `posted` as the dataset publication date. This confirms its use as release metadata and does not make it a specimen, testing, or individual laboratory reporting timestamp. The older compact metadata capture remains unchanged.

The README, concepts, dictionaries, methods, assumptions, practical guide, and source roles were checked for agreement. Pooled positivity still uses separate count denominators within each series. Missing, suppressed, invalid, and observed-zero values remain distinct. Window exclusions reuse one release; synthetic as-of histories remain separate. Math notation was checked against the implemented ratios, percentage-point differences, and denominators. No epidemiological inference or forecast is introduced.

## Validation

The Python suite ran 82 cases: 81 passed and one symbolic-link capability check was explicitly skipped on this Windows session. The three audit examples and both snapshot-preflight formats ran successfully. The synthetic and vintage outputs match the reference bytes; the public result differs only in the intentionally corrected chart footer. Its generated chart is valid UTF-8 XML, and its numerical/CSV outputs agree with the reference. The new later-capture fixture confirms that the footer reflects supplied metadata.
